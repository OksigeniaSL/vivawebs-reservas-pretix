# pretix-vivawebs

Complemento de [pretix](https://pretix.eu/) para el servicio de reservas de VivaWebs (Oksigenia S.L.): comprobación anti-robots invisible (Cloudflare Turnstile) al reservar, recordatorio por correo el día antes, tipografía del negocio, descarga de las reservas en CSV (`vw-exportar.php`, con clave en cabecera), redirección de `/reservas/` a la página de reservas e instalación sin formularios (`pretix vw_configurar datos.json`).
